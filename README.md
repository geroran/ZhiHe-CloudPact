# 智启云聚

**把分散的校园信息，汇聚到一个入口。**

智启云聚是面向云南大学师生的校园服务平台原型。项目围绕“找信息要在多个页面来回切换”的日常问题，把自然语言问答和可直接操作的校园工具放在一起，让查询空教室、了解充电口状态、查课程或浏览校园活动更方便。

> 本项目为 TRAE 黑客松参赛作品。部分功能依赖学校或第三方服务、网络环境及有效登录状态；实际可用范围以现场部署为准。上游服务不可用时，页面会提示连接或配置状态，不以虚构内容代替真实结果。

## 项目亮点

- **一个入口，两种使用方式**：可以直接用校园 AI 助手提问，也可以打开具体工具按条件查询。
- **面向真实校园场景**：围绕教室、充电、课程、集市和活动等高频需求设计。
- **结果来源清晰**：查询结果以对应服务的实际响应为准；接口不可用时会明确提示。
- **适配不同设备**：页面按桌面和手机场景设计，充电布局可在内容区域内滚动查看。

## 功能导览

| 功能 | 可以做什么 |
|---|---|
| 校园 AI 助手 | 用自然语言询问校园信息；通过学校智能体服务创建对话并查看回答。 |
| 空教室查询 | 选择校区、教学周、星期、节次和教学楼，查询空教室，并筛选结果。 |
| 桦苑充电口 | 查看桦苑充电口平面布局、端口状态和空闲端口列表。 |
| 校园集市 | 按自然语言需求查找校园集市信息，并查看检索结果。 |
| 教师 / 课程查询 | 按教师或课程查询课程安排、教学类型及相关详情。 |
| 学期课程 | 按学期查看课程名称、任课教师和课程安排。此功能不提供成绩或绩点查询。 |
| 到梦空间 | 查看活动列表、报名状态、名额和活动时间；仅提供查询，不提供报名或取消报名。 |
| 校历与校车 | 查看学期校历及校车运行时间资料。 |

## 适合谁使用

- **在校学生**：查询空教室、课程安排、充电口和校园活动；查找集市信息。
- **参赛评委**：体验自然语言入口与专用工具结合的校园服务流程，并了解各功能对应的真实数据服务。

## 技术框架

- **前端**：Vite 7、原生 JavaScript ES Modules、HTML5、CSS3；界面不依赖 React 或 Vue。
- **服务端**：Python 3，用于部分校园接口适配、服务端请求和凭据代理。
- **开发工具**：Node.js 与 npm，负责依赖管理、前端开发服务器和构建。
- **接口方式**：按模块对接校园智能体、教务、充电状态、校园集市及到梦空间等服务；需要登录或服务端凭据的功能通过相应 API 适配层处理。

## 本地运行

需要安装 Node.js 和 npm。进入项目目录后执行：

```bash
npm install
npm run dev
```

构建前端资源：

```bash
npm run build
```

`npm run dev` 启动 Vite 前端开发服务器。部分功能还依赖 Python 服务端或已部署的外部服务；如页面提示接口未配置或不可用，请检查 `.env.example` 中对应的配置项、服务地址、网络及登录状态。不要把个人凭据提交到代码仓库。

## 数据与使用说明

- 空教室、课程、充电和活动等结果受上游服务数据及可用性影响。
- 学期课程接口提供的是课程信息，不代表成绩信息；项目不会据此推算成绩、学分或绩点。
- 到梦空间模块为只读查询，不支持活动报名或取消报名。
- 校园集市回答应以实际检索结果为依据；数据源不可用时不会生成虚构帖子。
- 请勿在公开分享的截图、页面或代码中展示个人账号、登录凭据或密钥。
